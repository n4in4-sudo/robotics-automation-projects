### 2. Smart Home Lighting Automation
**Automation System Design**

A proposed Arduino-based smart lighting system using:
- Arduino Uno
- PIR motion sensor
- LDR light sensor
- Relay module
- Automated lamp control

The system uses motion detection and ambient light conditions to determine when the light should be switched on or off.

📄 [View Project Report](./Task_3_Smart_Home_Lighting/Smart_Home_Lighting_Automation.pdf)
